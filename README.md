# المصطفى للصيانة — موقع React (Vite)

## التشغيل
```
npm install
npm run dev        # تجربة على localhost
npm run build      # بناء النسخة النهائية في فولدر dist
```
(محتاج Node.js 18 أو أحدث)

## التعديل
- `src/config.js`   → الصور، رقم التليفون/الواتساب/الإيميل، سرعة السلايدر والعداد
- `src/content.js`  → كل النصوص بالعربي والإنجليزي
- `src/styles.css`  → الألوان والتصميم (المتغيرات في أول الملف)
- `public/images/`  → حط الصور هنا
